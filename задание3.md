# Индексация базы знаний для RAG (Задание 3)

## Модель эмбеддингов

- **Название:** BAAI/bge-base-en-v1.5
- **Ссылка:** https://huggingface.co/BAAI/bge-base-en-v1.5
- **Размер эмбеддинга:** 768
- **Библиотека:** sentence-transformers / LangChain (HuggingFaceEmbeddings)

## База знаний

- Папка: `knowledge_base/`
- 30+ документов (`.md`), описывающих сущности выдуманного мира,
  основанного на переработанной вселенной TMNT.
- Все ключевые исходные термины заменены согласно `terms_map.json`.

## Чанкование

- Инструмент: `RecursiveCharacterTextSplitter`
- Параметры:
    - `chunk_size = 1000` символов
    - `chunk_overlap = 200`
- На каждый чанк добавляются метаданные:
    - `source_path` — относительный путь к исходному файлу
    - `chunk_id` — порядковый номер чанка в индексе

## Индекс

- Векторная БД: **Chroma**
- Путь: `chroma_db/`
- Скрипт построения: `scripts/build_index.py`
- Скрипт запроса: `scripts/query_index.py`

После первого запуска:
- Общее число чанков выводится в консоль (например: `Всего чанков в индексе: 340`).
- Время генерации индекса также выводится (например: `Время генерации: 18.42 сек`).

Результат из командной строки:
- Всего чанков в индексе: 463
- Время генерации: 132.41 сек
